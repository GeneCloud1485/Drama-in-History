# Calculating Damage

1. Base damage = stagger value
2. + Base weapon damage
3. + Weapon threat damage
	1. Rolled 6's + Weapon's <u>Threat</u> when at effective reach, -1 if not at effective reach
		1. Unarmed = 0
		2. limited = +1
		3. Light = +2
		4. Mid = +3
		5. Heavy = +4
		6. Extreme = +5
	2. If total ≥Triple Wounds(1+)
4. + Hit Location 
	1. + Special Impacts bonuses
		1. ≥Triple of location number can trigger special effects
	2. Scale of impact can cause stagger
		1. Impact = Net successes + threat
		2. Impact ≥3 = stagger

 
**Any ≥triple 6's for loser = Parry opportunity**
